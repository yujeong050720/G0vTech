# 최소 암호화 문장 모델 실험

현재 프로젝트 루트에서 실행:

```powershell
..\.venv312\Scripts\python -m tiny_fhe.sentence_model
```

입력 예: `가상약A 1정 처방` 또는 `가상약B 1정 처방`.
sentence_model.py의 TRAINING_PAIRS에서 입력/답변 학습 쌍을 수정합니다.
매 실행 시 작은 모델을 다시 학습합니다. 학습 데이터와 가중치는 비밀 데이터로 취급하지 않습니다.

## 실제 수행하는 계산

1. 단어 빈도 입력 벡터와 답변 위치별 정답 토큰을 준비합니다.
2. 교차 엔트로피 경사하강법으로 선형 가중치를 학습합니다.
3. 사용자 측에서 입력 벡터를 CKKS 암호화하고 비밀키를 보관합니다.
4. 별도 프로세스에 공개 컨텍스트·암호문·모델 가중치만 담은 ZIP을 전달합니다.
5. 해당 프로세스는 암호문 행렬 곱으로 모든 답변 위치의 점수를 계산합니다.
6. 사용자 측에서 점수를 복호화하고 위치별 argmax로 토큰을 골라 전체 문장을 구성합니다.

서버가 문장을 검색해 반환하는 방식은 아닙니다. 실제 학습된 가중치를 암호문에 적용합니다.
다만 Transformer/범용 LLM/자기회귀 생성 모델은 아닙니다. 출력 길이가 고정된 아주 작은
조건부 토큰 모델이며, 토큰 선택은 복호화 후 사용자 측에서 합니다.
지원하는 학습 입력만 허용합니다. 문장 이해·일반화·의약품 지식을 검증하지 않았습니다.
가상 약물의 합성 예시이므로 의료 안내로 사용하지 마세요.
실행은 동일 PC의 별도 프로세스입니다. 프로세스를 OS 권한으로 격리한 보안 배포가 아니며,
원격 배포·출력 무결성의 암호학적 증명·악성 서버 방어를 검증한 것은 아닙니다.

## API

서버를 Ctrl+C로 종료한 다음:

```powershell
$env:MEDICATION_MODEL = 'sentence-fhe'
..\.venv312\Scripts\python app.py
```

기존 LOCAL_API_TOKEN 인증을 유지합니다. POST /medication-info 요청:

```json
{"prescription":"가상약A 1정 처방"}
```

답변은 explanation 필드입니다. 미지원 문장은 422, 실행 환경 오류는 503입니다.
CLI는 인증 토큰 없이 로컬 실험을 실행하므로 처음에는 CLI를 권장합니다.

검증: `python -m unittest discover -s tests -p test_sentence_model.py -v`
실제 CKKS 두 문장 왕복(하나는 API 경유) 및 미지원 입력 거부: 3개 통과.
이전 음악/산책용 테스트는 CORPUS 변경 전 기준이며 이 문장 모델의 검증과 구분합니다.
